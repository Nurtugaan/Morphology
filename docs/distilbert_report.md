# Отчет по обучению модели DistilBERT для казахской морфологии

## 1. Обзор конфигураций обучения

В ходе исследования были протестированы три различные конфигурации данных для обучения модели `distilbert-base-multilingual-cased`:

1.  **gold_only**: Обучение только на проверенных вручную данных (KTB - Kazakh Treebank).
2.  **gold_silver**: Обучение на комбинации KTB и большого объема автоматически размеченных данных (Silver).
3.  **nlanu_only**: Обучение на корпусе NLANU, который значительно больше KTB по объему.

---

## 2. Сравнение результатов (Test Set)

Ниже приведены итоговые метрики моделей на тестовых наборах данных.

| Конфигурация | Размер (предложений) | Accuracy | Precision | Recall | F1-score |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **gold_only** | 942 | 0.4915 | 0.1345 | 0.1384 | 0.1206 |
| **gold_silver** | 28335 | 0.5047 | 0.2094 | 0.2288 | 0.2065 |
| **nlanu_only** | 61111 (всего) | **0.9696** | **0.6571** | **0.6534** | **0.6470** |

---

## 3. Анализ динамики обучения

### gold_only
- **Результат**: Крайне низкий F1-score (12%).
- **Причина**: Недостаток данных (всего 942 предложения). Модель не успевает выучить многообразие казахской морфологии и переобучается на специфике малого корпуса.

### gold_silver
- **Результат**: Улучшение F1 до 20%.
- **Причина**: Добавление "Silver" данных помогло модели лучше обобщать, однако качество автоматической разметки ограничивает максимальный результат. Разрыв между обучающей и валидационной лоссами указывает на шум в данных.

### nlanu_only
- **Результат**: Значительный скачок (F1 ~65%, Accuracy ~97%).
- **Причина**: 
    1. **Объем**: Корпус NLANU в десятки раз больше KTB.
    2. **Чистота**: Данные NLANU оказались более консистентными для данной архитектуры.
    3. **Стабильность**: Модель показала стабильное снижение лосса и рост метрик на протяжении всех 6 эпох.

---

## 4. Выводы и рекомендации

1.  **Зависимость от объема**: Для казахской морфологии критически важен объем обучающей выборки. Переход от тысячи к десяткам тысяч предложений дает кратный прирост точности.
2.  **Эффективность DistilBERT**: Модель `distilbert-base-multilingual-cased` показывает отличную производительность (Accuracy 97%) на чистых данных большого объема, что делает ее пригодной для интеграции в итоговую систему.
3.  **Дальнейшие шаги**: 
    - Протестировать полную версию BERT (не Distil) на корпусе NLANU.
    - Изучить ошибки модели на сложных морфологических категориях (падежи, притяжательные формы).
    - Опробовать аугментацию данных для KTB, чтобы повысить его значимость.
