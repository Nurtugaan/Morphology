### TASK-003 — Предобработка данных

**Статус:** ✅ Выполнено

Реализован полный pipeline предобработки данных для задачи token classification. Код расположен в `services/preprocessing/en_preprocessing.py` (~811 строк).

**Реализованные компоненты:**

1. **Парсинг CoNLL-U файлов** — извлечение полей FORM, LEMMA, UPOS, FEATS
2. **Фильтрация токенов** — исключение мультислов (ID "1-2") и пустых узлов (ID "3.1")
3. **Генерация меток** — формат `UPOS|FEATS` (например, `VERB|Tense=Past|Number=Sing`)
4. **Словарь меток** — построение `label2id` / `id2label` маппингов
5. **Подготовка для трансформеров** — выравнивание субтокенов (label alignment), `-100` для padding

**Статистика меток:** 406 уникальных комбинаций `UPOS|FEATS`

**Артефакт:** [TASK-003-DATA-PREPROCESSING-EN.md](TASK-003-DATA-PREPROCESSING-EN.md)

## 📊 Результаты экспериментов

### Сравнительная таблица (Test Set)

| # | Модель | Accuracy | Precision | Recall | Macro-F1 | Параметры | Время обучения |
|---|--------|----------|-----------|--------|----------|-----------|---------------|
| 🥇 | **DistilBERT** | 94.89% | 59.92% | 59.32% | **58.84%** | 66M | 25.9 мин |
| 🥈 | BERT-base | 94.83% | 57.83% | 57.31% | 56.79% | 109M | 38.6 мин |
| 🥉 | ALBERT-base | 94.64% | 57.71% | 56.11% | 56.09% | 12M | 49.0 мин |

| 5 | Flair | 93.95% | 54.92% | 51.21% | 52.08% | 63M | ~30 мин |

### Анализ результатов

- **Accuracy (~94–95%)** — все трансформеры показывают схожую общую точность, что говорит о высоком качестве базовых предсказаний
- **Macro-F1 (52–59%)** — относительно низкий показатель объясняется наличием ~400 уникальных меток с длиннохвостым распределением (многие классы встречаются < 10 раз)
- **DistilBERT** — лучший баланс между качеством и скоростью: наивысший F1 при самом быстром обучении и наименьшем размере среди трансформеров
- **Flair (BiLSTM+CRF)** — уступает трансформерам на 3–7% по Macro-F1, что подтверждает преимущество архитектуры attention для задач морфологического анализа

## 🏗 Архитектура проекта

Создана полная структура проекта, включая:

```
morphology/
├── backend/                    # FastAPI API-сервер
│   └── app/
│       ├── api/routes/         # Endpoints: /api/models, /api/analyze
│       ├── services/           # Сервис загрузки и inference моделей
│       └── main.py             # Точка входа FastAPI
│
├── frontend/                   # Веб-интерфейс (Vite + React)
│   └── src/
│       ├── App.jsx             # Главный компонент
│       ├── components/         # UI-компоненты
│       └── services/           # API-клиент
│
├── services/
│   ├── datasets/english/       # Корпуса UD English EWT + GUM
│   ├── preprocessing/          # Пайплайн обработки данных
│   ├── training/               # Модули обучения моделей
│   ├── evaluation/             # Метрики и отчёты
│   └── models/en/              # 5 обученных моделей
│
└── docs/                       # Документация и логи обучения
```

**Backend (FastAPI):**
- REST API для интерактивного тестирования моделей
- Endpoints: `GET /api/models`, `POST /api/analyze`
- Поддержка выбора модели из доступных (DistilBERT, BERT, RoBERTa, ALBERT)

**Frontend (Vite + React):**
- Веб-интерфейс для ввода текста и отображения результатов морфологического анализа

## 🔑 Ключевые выводы

1. **DistilBERT** — лучший выбор для морфологического анализа: высший Macro-F1 (58.84%), самое быстрое обучение (25.9 мин), оптимальный размер (66M параметров)
2. **Accuracy ~95%** достижима всеми трансформерами — архитектуры одинаково хорошо справляются с частотными классами
3. **Macro-F1 ~55–60%** — нормальный результат для задачи с ~400 классами, обусловлен long-tail распределением меток
4. **Трансформеры превосходят BiLSTM+CRF** (Flair) на 3–7% по Macro-F1, что подтверждает эффективность механизма self-attention для морфологических задач
5. **Методика полностью воспроизводима** — фиксированный seed (42), все гиперпараметры задокументированы, логи обучения сохранены
