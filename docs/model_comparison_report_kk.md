# DistilBERT және mBERT модельдерін салыстыру есебі (NLANU корпусы)

Бұл есепте қазақ тілінің морфологиялық талдау міндеті үшін NLANU корпусында оқытылған екі трансформер архитектурасы — **DistilBERT** және **mBERT** (multilingual BERT) салыстырмалы талдауы келтірілген.

## 1. Тесттік жиынтықтағы қорытынды көрсеткіштер (Test Results)

|    Метрика    |   DistilBERT (base-multilingual) |  mBERT (bert-base-multilingual) |
| :------------ | :------------------------------: | :-----------------------------: |
| **Accuracy**  |            0.9696                |              0.9773             |
| **Precision** |            0.6571                |              0.7288             |
| **Recall**    |            0.6534                |              0.7375             |
| **F1-Score**  |            0.6470                |              0.7259             |

## 2. Тиімділік және ресурстар

|             Параметр          | DistilBERT |   mBERT    |             Қатынасы           |
| :---------------------------- | :--------: | :--------: | :----------------------------: |
| **Параметрлер саны**          |  ~135 млн  | ~178 млн   | mBERT 32%-ға ауыр              |
| **Оқыту уақыты (6 дәуір)**    |  58.0 мин  | 109.8 мин  | mBERT 1.9 есе баяу             |
| **Жылдамдығы (итерация/сек)** | ~2.95 it/s | ~1.55 it/s | DistilBERT 2 есеге жуық жылдам |

## 3. Нәтижелерді талдау

### Өнімділік (F1-Score)
mBERT талдау сапасы бойынша айтарлықтай артықшылық көрсетті. **F1-score көрсеткішінің 8%-ға өсуі** (64.7%-дан 72.6%-ға дейін) дипломдық жұмыс үшін маңызды болып табылады. mBERT қабаттар мен параметрлердің көптігі арқасында сирек кездесетін морфологиялық формаларды жақсырақ меңгереді.

### Жылдамдық пен жеңілдік
DistilBERT өзінің "жеңілдетілген" модель ретіндегі атауын ақтайды. Ол 1 сағатта оқытылса, mBERT-ке дәл сол жабдықта 2 сағатқа жуық уақыт қажет. Егер қосымша үшін жауап беру жылдамдығы (latency) маңызды болса, DistilBERT қолайлы болуы мүмкін.

### Оқыту динамикасы (Loss)
- Екі модель де 6 дәуірде тұрақты жинақталғыштықты көрсетті.
- **mBERT Val Loss**: 0.0900 (6-шы дәуірде).
- **DistilBERT Val Loss**: 0.1196 (6-шы дәуірде).
mBERT-тің лосс (loss) көрсеткішінің төмен болуы модельдің қазақ тілінің құрылымын жақсырақ "түсінетінін" дәлелдейді.

## 4. Қорытынды

1. **Дәлдік бойынша ұсыныс**: Морфологиялық талдауда максималды дәлдікке қол жеткізу үшін **mBERT** моделін пайдалану ұсынылады.
2. **Енгізу бойынша ұсыныс**: Егер аппараттық ресурстар шектеулі болса (мысалы, GPU жоқ әлсіз серверде іске қосылғанда), **DistilBERT**-ті қалдыруға болады, өйткені `Accuracy` айырмашылығы үлкен емес (~0.8%), бірақ `F1` (тегтер бойынша дәлдік) айтарлықтай ерекшеленеді.
3. **Қорытынды таңдау**: Дипломдық жұмыстың соңғы бөлімі үшін mBERT неғұрлым күшті кандидат болып табылады, ол жүйенің нақты мәтіндермен 72.6% F1 деңгейінде жұмыс істеуге дайындығын көрсетеді.
