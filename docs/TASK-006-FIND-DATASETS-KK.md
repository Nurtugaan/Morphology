# TASK-006: Қазақ тіліндегі морфологиялық корпустарды іздеу

## 1. Тапсырмаға шолу
Бұл тапсырманың мақсаты қазақ тілінің морфологиялық талдау модельдерін оқытуға арналған қолданыстағы корпустарды (деректер жиынтығын) іздеу және талдау болды. Олардың көлемін, форматын және жоба аясында қолдануға жарамдылығын бағалау қажет болды.

## 2. Табылған деректер жиынтығы

Зерттеу барысында екі негізгі дереккөз анықталды:

1.  **UD Kazakh KTB (Universal Dependencies)**
2.  **KazDET (NLANU) -> UD форматына түрлендірілген**

### 2.1. UD Kazakh KTB (Kyoto Treebank)
Қазақ тіліне арналған ресми Universal Dependencies корпусы.

*   **Мәртебесі:** Gold Standard (қолмен белгіленген/тексерілген).
*   **Форматы:** CoNLL-U.
*   **Құрамы:**
    *   `kk_ktb-ud-train.conllu`: Оқыту жиынтығы.
    *   `kk_ktb-ud-test.conllu`: Тесттік жиынтығы.

**Статистика:**

| Файл                     | Сөйлемдер | Токендер | Сипаттамасы                      |
| :----------------------- | :-------- | :------- | :------------------------------- |
| `kk_ktb-ud-train.conllu` | 1047      | 10007    | Негізгі оқыту жиынтығы.          |
| `kk_ktb-ud-test.conllu`  | 31        | 529      | Тесттік жиынтық (көлемі өте аз). |
| **Барлығы**              | 1078      | 10536    |                                  |

*   **Таңдау себебі:** Белгілеу сапасының жоғарылығы, UD v2 стандартына сәйкестігі.

### 2.2. KazDET (NLANU)
Бастапқыда KazDET форматында болған ірі корпус, біз оны `convert_kazdet_to_ud.py` скриптінің көмегімен UD v2 форматына түрлендірдік.

*   **Мәртебесі:** Silver Standard (автоматты түрлендіру).
*   **Форматы:** CoNLL-U (түрлендіруден кейін).
*   **Файл:** `kdt-NLANU-ud.conllu`.

### 2.3. KazDET (NLANU) - Бастапқы файл
Бұл NLANU-дан алынған түпнұсқа файл, көлемі айтарлықтай үлкен

*   **Файл:** `services/datasets/kazakh/NLANU/kdt-NLANU-0.01.connlu`.
*   **Күйі:** Raw / Өңделмеген.
*   **Мәселелері:** Кодтау артефактілері байқалды (мысалы, `ҚТЖ` орнына `ТљРўР–`). Кодтауды қалпына келтіруді талап етеді (шамамен CP1251 -> UTF-8 немесе қосарланған кодтау).

**Статистика (Бастапқы vs Түрлендірілген):**

| Метрика          | KazDET (Түрлендірілген) | KazDET (Бастапқы дереккөз) |
| :--------------- | :--------------------- | :------------------------ |
| **Сөйлемдер**    | 27 393                  | 61 111                    |
| **Токендер**     | 287 083                 | 934 731                   |
| **Бірегей UPOS** | 17                      |                           |

**Негізгі сөз таптарының үлестірімі (UPOS):**
*   NOUN: ~88k
*   VERB: ~35k
*   PROPN: ~30k
*   ADJ: ~30k
*   PUNCT: ~52k

*   **Таңдау себебі:** Деректер көлемінің үлкендігі (шамамен 300 мың токен), мәтіндердің алуан түрлілігі.

## 3. Салыстырмалы талдау

| Сипаттама | UD Kazakh KTB | KazDET (Түрлендірілген) |
| :--- | :--- | :--- |
| **Көлемі (токендер)** | ~10k | ~287k (~934k бастапқыдан) |
| **Сапасы** | Жоғары (Gold) | Орташа (Silver, auto-converted) |
| **Мақсаты** | Валидация, Тестілеу | Оқыту (Pre-training / Training) |
| **Тегтердің толықтығы** | Толық UD жиынтығы | Базовый UD жиынтығы + түрлендірілген FEATS |

## 4. Қорытындылар мен ұсыныстар

1.  **Негізгі деректер жиынтығы:** UD KTB көлемі жеткіліксіз болғандықтан, **KazDET**-ті модельдерді оқыту үшін негізгі дереккөз ретінде пайдалану.
2.  **Валидация:** **UD KTB** (train бөлігін) валидациялық жиынтық (Dev set) ретінде пайдалану, өйткені оның эталондық белгілеуі бар.
3.  **Тестілеу:** Финалдық тестілеу үшін **UD KTB** (test бөлігін) пайдалану, бірақ оның көлемі аз (31 сөйлем) екенін ескере отырып, репрезентативті тесттік жиынтықты қалыптастыру үшін UD KTB Train немесе KazDET-тен (қолмен тексергеннен кейін) сөйлемдердің бір бөлігін бөлу ұсынылады.
4.  **Алдын ала өңдеу:** Бұл деректер жиынтығын біртұтас пайплайнға біріктіру, (қажет болса) қайта белгілеуді және тегтерді стандарттауды іске асыру қажет.
