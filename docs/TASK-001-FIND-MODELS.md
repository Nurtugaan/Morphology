**Задача:** Исследовать существующие трансформер-модели и архитектуры для задач token classification и морфологического анализа

---

## Цель

Найти и сравнить архитектуры, применимые для морфологического анализа (token classification), определить модели-кандидаты для обучения и формализовать критерии их отбора.

---

## Критерии отбора моделей

При выборе моделей учитывались следующие факторы:

1. **Поддержка token-level задач** — модель должна быть применима к token classification (POS, Morphology)
2. **Наличие предобученных весов** — доступность на [HuggingFace Hub](https://huggingface.co/models)
3. **Размер модели** — возможность обучения на GPU с 8–16 GB VRAM (Google Colab / Kaggle)
4. **Разнообразие архитектур** — для корректного сравнения необходимо включить модели разных типов (encoder-only, distilled, RNN)
5. **Актуальность** — модели, активно используемые в академических исследованиях

## Рассмотренные модели

| Модель        | Архитектура | Размер / Параметры | Задачи                    | Сильные стороны                               | Слабые стороны                         |
| ------------- | ----------- | ------------------ | ------------------------- | --------------------------------------------- | -------------------------------------- |
| BERT-base     | BERT        | base / 110M        | POS, Morphology, NER      | Высокая точность, хорошо обучен на английском | Большой размер, медленный inference    |
| BERT-large    | BERT        | large / 340M       | POS, Morphology, NER      | Более высокая точность                        | Очень большой размер, медленный        |

| RoBERTa-large | RoBERTa     | large / 355M       | POS, Token Classification | Высокая точность                              | Очень большой размер                   |
| DistilBERT    | BERT        | small / 66M        | POS, Token Classification | Быстрая inference, лёгкая модель              | Немного ниже точность                  |
| ALBERT-base   | ALBERT      | base / 12M         | POS, Morphology           | Экономия памяти, быстрый inference            | Меньше точность чем у BERT             |
| ALBERT-large  | ALBERT      | large / 18M        | POS, Morphology           | Более точная чем ALBERT-base                  | Всё ещё уступает BERT-large            |
| DistilRoBERTa | RoBERTa     | small / 82M        | POS, Token Classification | Быстрая inference, лёгкая                     | Меньше точность чем базовая RoBERTa    |
| Flair         | LSTM+Char   | —                  | POS, NER                  | Лёгкая, эффективная для экспериментов         | Не трансформер, устаревающая           |
| BERT-Morph    | BERT        | —                  | Morphology                | Специализирован для морфологии                | Ограничено по языкам, редко pretrained |

### Причины отсева

- **BERT-large / RoBERTa-large** — слишком большие для обучения на Colab/Kaggle (>16 GB VRAM), не дают значительного прироста для данной задачи
- **DistilRoBERTa** — дублирует нишу DistilBERT, менее распространена в исследованиях
- **BERT-Morph** — ограниченная доступность pretrained весов, мало документации
