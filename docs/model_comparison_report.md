# Отчет о сравнении моделей DistilBERT и mBERT (Корпус NLANU)

В данном отчете проводится сравнительный анализ двух архитектур трансформеров — **DistilBERT** и **mBERT** (multilingual BERT), обученных на корпусе NLANU для задачи морфологического анализа казахского языка.

## 1. Итоговые показатели на тестовом наборе (Test Results)

| Метрика | DistilBERT (base-multilingual) | mBERT (bert-base-multilingual) |
| :--- | :---: | :---: |
| **Accuracy** | 0.9696 | **0.9773** |
| **Precision** | 0.6571 | **0.7288** |
| **Recall** | 0.6534 | **0.7375** |
| **F1-Score** | 0.6470 | **0.7259** |

## 2. Эффективность и ресурсы

| Параметр | DistilBERT | mBERT | Соотношение |
| :--- | :---: | :---: | :---: |
| **Кол-во параметров** | ~135 млн | ~178 млн | mBERT на 32% тяжелее |
| **Время обучения (6 эпох)** | 58.0 мин | 109.8 мин | mBERT в 1.9 раза медленнее |
| **Скорость (итераций/сек)** | ~2.95 it/s | ~1.55 it/s | DistilBERT почти в 2 раза быстрее |

## 3. Анализ результатов

### Производительность (F1-Score)
mBERT показал значительное превосходство в качестве анализа. Прирост **F1-score на 8%** (с 64.7% до 72.6%) является критическим для дипломной работы. mBERT лучше справляется с редкими морфологическими формами благодаря большему количеству слоев и параметров.

### Скорость и легкость
DistilBERT оправдывает свое название как "облегченная" модель. Она обучается за 1 час, в то время как mBERT требует почти 2 часа на том же оборудовании. Если в итоговом приложении критична скорость отклика (latency) на CPU, DistilBERT может быть предпочтительнее.

### Динамика обучения (Loss)
- Обе модели показали стабильнуюходимость на 6 эпохах.
- **mBERT Val Loss**: 0.0900 (на 6 эпохе).
- **DistilBERT Val Loss**: 0.1196 (на 6 эпохе).
Более низкий `loss` у mBERT подтверждает, что модель лучше "понимает" структуру казахского языка.

## 4. Выводы

1. **Рекомендация по точности**: Для достижения максимальной точности в морфологическом разборе рекомендуется использовать **mBERT**.
2. **Рекомендация по внедрению**: Если аппаратные ресурсы ограничены (например, при запуске на слабом сервере без GPU), можно оставить **DistilBERT**, так как разница в `Accuracy` (общая точность попадания символа) невелика (~0.8%), хотя `F1` (точность по тегам) отличается существенно.
3. **Итоговый выбор**: Для финальной части дипломной работы mBERT является более сильным кандидатом, демонстрируя готовность системы к работе с реальными текстами на уровне 72.6% F1.
