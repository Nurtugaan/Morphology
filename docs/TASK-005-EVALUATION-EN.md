**Дата:** 2026-02-07  
**Статус:** ✅ Выполнено  
**Задача:** Сравнить модели по ключевым метрикам и выбрать лучшие для перехода к казахскому языку

## Анализ результатов

### Accuracy (~94–95%)

Все трансформеры показывают очень близкую accuracy (~94.8%), что говорит о:
- Схожем качестве базовых предсказаний
- Одинаковой способности классифицировать частотные метки (NOUN|Number=Sing, PUNCT|_, ADP|_ и др.)

### Macro-F1 (52–59%)

Относительно низкий Macro-F1 объясняется:
- **~406 уникальных меток** — многие встречаются < 10 раз в тестовом наборе
- **Long tail distribution** — редкие классы (Typo=Yes, Abbr=Yes, Style=Expr) получают F1=0.0 и сильно влияют на macro-среднее
- Это **нормальное поведение** для морфологического анализа с полным набором FEATS

### Разбор по категориям меток (на примере Flair)

| Категория | Примеры | F1 | Комментарий |
|-----------|---------|-----|-------------|
| **Частые метки** (>500) | NOUN\|Number=Sing, PUNCT\|_, ADP\|_ | 93–99% | Все модели справляются отлично |
| **Средние** (50–500) | ADJ\|Degree=Sup, PROPN\|Number=Plur | 70–95% | Хорошее качество |
| **Редкие** (10–50) | NOUN\|Number=Ptan, ADV\|Degree=Sup | 30–70% | Нестабильные результаты |
| **Очень редкие** (<10) | Typo=Yes, Abbr=Yes, Style=Expr | 0–30% | Недостаточно данных для обучения |

> Примеры хорошо предсказываемых меток: `DET|Definite=Def|PronType=Art` (F1: 99.9%), `CCONJ|_` (F1: 99.3%), `PART|Polarity=Neg` (F1: 99.5%)

> Примеры плохо предсказываемых меток: `X|_` (F1: 21.2%), `NOUN|Number=Ptan` (F1: 28.6%), `NUM|NumForm=Roman|NumType=Card` (F1: 0.0%)

### Сравнение архитектур

| Аспект | Трансформеры (4 модели) | Flair (BiLSTM+CRF) |
|--------|------------------------|-------------------| 
| Macro-F1 | 55–59% | 52% |
| Контекст | Глобальный (self-attention) | Локальный (LSTM) |
| CRF | Нет | Да (улучшает согласованность последовательности) |
| Субтокенизация | Да (WordPiece / SentencePiece / BPE) | Нет (char-level embeddings) |
| Скорость обучения | 26–49 мин | ~30 мин |

**Вывод:** Трансформеры превосходят BiLSTM+CRF на 3–7% по Macro-F1 благодаря механизму self-attention, который лучше захватывает глобальный контекст предложения.

## Рекомендации для казахского языка

### 1. Основная модель: DistilBERT (для методологии)

- ✅ **Лучший Macro-F1** (58.84%)
- ✅ **Самое быстрое обучение** (25.9 мин)
- ✅ **Оптимальный размер** (66M параметров)
- ✅ Хорошо подходит для production

### 2. Резервная модель: BERT-base

- Второй по F1 (56.79%)
- Надёжный baseline для сравнения
- Больше документации и примеров

### 3. Применение к казахскому языку

> **Для казахского языка будет использоваться Kaz-RoBERTa**, но гиперпараметры и методика обучения будут основаны на результатах Sprint 1:

| Параметр | Рекомендуемое значение | Обоснование |
|----------|----------------------|-------------|
| Learning rate | 3e-5 | Лучший результат у DistilBERT с lr=3e-5 |
| Epochs | 6 | Метрики продолжают расти до 6-й эпохи |
| Batch size | 32 | Оптимальный баланс скорость/качество |
| Warmup ratio | 0.1 | Стабильная сходимость |
| Weight decay | 0.01 | Без overfitting |

## Выводы

1. **DistilBERT** — лучший выбор для морфологического анализа: лучшее соотношение качества, скорости и размера
2. **Accuracy ~95%** достижима всеми трансформерами — архитектуры одинаково хорошо справляются с частотными метками
3. **Macro-F1 ~55–60%** — нормальный результат для задачи с 400+ классами, обусловлен long-tail распределением
4. **Основная проблема** — редкие метки (< 10 примеров) предсказываются плохо или вообще не предсказываются
5. **Методика переносима** на казахский язык с адаптацией под Kaz-RoBERTa
