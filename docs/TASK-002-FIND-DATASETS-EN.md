## 1. Общие требования к датасетам

Для обучения и сравнения моделей морфологического анализа были предъявлены следующие требования к корпусам данных:

* наличие **морфологической разметки на уровне токенов**;
* поддержка **POS-тегов и морфологических признаков (FEATS)**;
* формат данных, совместимый с задачами **token classification**;
* возможность использования с трансформер-моделями (BERT, RoBERTa и др.);
* открытая лицензия и свободный доступ.

На основании этих критериев были выбраны два корпуса из проекта **Universal Dependencies**.

---

## 2. Выбранные датасеты

### 2.1 Universal Dependencies – English Web Treebank (UD English EWT)

#### 📌 Назначение

Используется как **основной обучающий датасет**.

#### 📊 Общие характеристики

| Параметр               | Значение                           |
| ---------------------- | ---------------------------------- |
| Язык                   | Английский                         |
| Формат                 | CoNLL-U                            |
| Количество предложений | ~16 000                            |
| Количество токенов     | ~250 000                           |
| Аннотация              | UPOS, XPOS, FEATS, Lemma           |
| Тип текстов            | Веб-тексты (блоги, статьи, форумы) |

#### 🧠 Морфологические параметры

В датасете представлены стандартные морфологические признаки Universal Dependencies, включая:

* Number (Sing, Plur)
* Tense (Past, Pres)
* Mood
* Person
* Degree
* VerbForm и др.

Все признаки содержатся в поле **FEATS**, что позволяет формулировать задачу как:

* multi-class token classification;
* multi-label морфологическую классификацию;
* multi-task learning (POS + Morphology).

#### ✅ Преимущества

* стандарт де-факто в академических исследованиях;
* высокая совместимость с трансформер-моделями;
* тексты приближены к реальным веб-данным;
* достаточный объём для обучения baseline-моделей.

#### ⚠️ Ограничения

* наличие шума (разговорная речь, нестандартная пунктуация);
* веб-ориентированный домен.

---

### 2.2 Universal Dependencies – English GUM (UD English GUM)

#### 📌 Назначение

Используется как **дополнительный и сравнительный датасет**.

#### 📊 Общие характеристики

| Параметр               | Значение                                                         |
| ---------------------- | ---------------------------------------------------------------- |
| Язык                   | Английский                                                       |
| Формат                 | CoNLL-U                                                          |
| Количество предложений | ~7 000–8 000                                                     |
| Количество токенов     | ~170 000                                                         |
| Аннотация              | UPOS, XPOS, FEATS, Lemma                                         |
| Тип текстов            | Многожанровые (академические, интервью, художественные, новости) |

#### 🧠 Морфологические параметры

Используется **та же схема морфологических признаков**, что и в UD English EWT, включая FEATS, что обеспечивает:

* единое пространство меток;
* корректное сравнение моделей;
* отсутствие необходимости в преобразовании разметки.

#### ✅ Преимущества

* разнообразие жанров и стилей текста;
* более формальный и грамматически корректный язык;
* меньший уровень шума;
* полностью совместим с UD English EWT.

#### ⚠️ Ограничения

* меньший объём данных;
* не предназначен для обучения «с нуля».

---

## 3. Причины выбора именно этих датасетов

Выбор **UD English EWT** и **UD English GUM** обусловлен следующими факторами:

1. Оба датасета:

   * используют **единую Universal Dependencies схему**;
   * представлены в формате **CoNLL-U**;
   * содержат **морфологические признаки (FEATS)**.

2. Комбинация датасетов позволяет:

   * обучать модель на одном домене (EWT);
   * тестировать обобщающую способность на другом (GUM);
   * анализировать устойчивость модели к смене жанра текста.

3. Датасеты являются:

   * открытыми;
   * воспроизводимыми;
   * широко используемыми в научных публикациях.

---

## 4. Итоговая схема использования

| Этап                | Датасет        |
| ------------------- | -------------- |
| Обучение (training) | UD English EWT |
| Валидация / тест    | UD English GUM |
| Анализ обобщения    | EWT → GUM      |

---

## 5. Формулировка для дипломной работы

> *В качестве основного обучающего корпуса был выбран датасет Universal Dependencies English Web Treebank, содержащий морфологическую и POS-разметку в формате CoNLL-U. Для оценки способности модели к обобщению и анализа влияния домена был использован дополнительный корпус Universal Dependencies English GUM, включающий тексты различных жанров.*
