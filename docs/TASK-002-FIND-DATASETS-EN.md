# TASK-002: Морфологиялық талдау үшін ағылшын тіліндегі деректер жиынтығын іздеу

**Күні:** 2026-02-05  
**Мәртебесі:** ✅ Орындалды  
**Тапсырма:** Морфологиялық таңбалауы бар дайын ағылшын тілді корпустарды табу және талдау

---

## Мақсаты

Ағылшын тіліндегі token classification модельдерін оқыту және бағалау үшін морфологиялық аннотациясы бар ашық деректер жиынтығын табу.

---

## 1. Деректер жиынтығына қойылатын жалпы талаптар

Морфологиялық талдау модельдерін оқыту және салыстыру үшін деректер корпустарына келесі талаптар қойылды:

* **токеңдер деңгейінде морфологиялық таңбалаудың** болуы;
* **POS-тегтер мен морфологиялық белгілерді (FEATS)** қолдау;
* **token classification** тапсырмаларымен үйлесімді деректер форматы;
* трансформер-модельдермен (BERT, RoBERTa және т.б.) пайдалану мүмкіндігі;
* ашық лицензия және еркін қолжетімділік.

Осы критерийлер негізінде [**Universal Dependencies**](https://universaldependencies.org/) жобасынан екі корпус таңдалды.

---

## 2. Таңдалған деректер жиынтығы

### 2.1 Universal Dependencies – English Web Treebank (UD English EWT)

#### 📌 Мақсаты

**Негізгі оқыту деректер жиынтығы** ретінде пайдаланылады.

#### 📊 Жалпы сипаттамалары

| Параметр               | Мәні                               |
| ---------------------- | ---------------------------------- |
| Тіл                    | Ағылшын                            |
| Формат                 | CoNLL-U                            |
| Сөйлемдер саны         | 16 622 (train: 12 544 / dev: 2 001 / test: 2 077) |
| Токеңдер саны          | 254 818 (train: 204 577 / dev: 25 147 / test: 25 094) |
| Аннотация              | UPOS, XPOS, FEATS, Lemma           |
| Мәтін түрі             | Веб-мәтіндер (блогтар, мақалалар, форумдар) |
| Сілтеме                | [UD English EWT](https://github.com/UniversalDependencies/UD_English-EWT) |

#### 🧠 Морфологиялық параметрлер

Деректер жиынтығында Universal Dependencies стандартты морфологиялық белгілері ұсынылған, соның ішінде:

* Number (Sing, Plur)
* Tense (Past, Pres)
* Mood
* Person
* Degree
* VerbForm және т.б.

Барлық белгілер **FEATS** өрісінде орналасқан, бұл тапсырманы келесідей тұжырымдауға мүмкіндік береді:

* multi-class token classification;
* multi-label морфологиялық классификация;
* multi-task learning (POS + Morphology).

#### ✅ Таңдау себептері

* академиялық зерттеулердегі де-факто стандарт;
* трансформер-модельдермен жоғары үйлесімділік;
* мәтіндер шынайы веб-деректерге жақын;
* baseline-модельдерді оқыту үшін жеткілікті көлем.

#### ⚠️ Шектеулері

* шудың болуы (сөйлеу тілі, стандартты емес пунктуация);
* веб-бағытталған домен.

### 2.2 Universal Dependencies – English GUM (UD English GUM)

#### 📌 Мақсаты

**Қосымша және салыстырмалы деректер жиынтығы** ретінде пайдаланылады.

#### 📊 Жалпы сипаттамалары

| Параметр               | Мәні                                                         |
| ---------------------- | ---------------------------------------------------------------- |
| Тіл                    | Ағылшын                                                       |
| Формат                 | CoNLL-U                                                          |
| Сөйлемдер саны         | 13 263 (train: 10 224 / dev: 1 575 / test: 1 464) |
| Токеңдер саны          | 233 926 (train: 177 410 / dev: 28 119 / test: 28 397) |
| Аннотация              | UPOS, XPOS, FEATS, Lemma                                         |
| Мәтін түрі             | Көп жанрлы (академиялық, сұхбат, көркем әдебиет, жаңалықтар) |
| Сілтеме                | [UD English GUM](https://github.com/UniversalDependencies/UD_English-GUM) |

#### 🧠 Морфологиялық параметрлер

UD English EWT-дегідей **морфологиялық белгілер схемасы** қолданылады, соның ішінде FEATS, бұл келесілерді қамтамасыз етеді:

* бірыңғай белгілер кеңістігі;
* модельдерді дұрыс салыстыру;
* таңбалауды түрлендіру қажеттілігінің болмауы.

#### ✅ Таңдау себептері

* мәтін жанрлары мен стильдерінің әртүрлілігі;
* ресми және грамматикалық тұрғыдан дұрыс;
* шу деңгейінің төмендігі;
* UD English EWT-мен толық үйлесімді.

#### ⚠️ Шектеулері

* деректер көлемінің азырақ болуы;
* "нөлден" оқытуға арналмаған.

## 4. Дәл осы деректер жиынтығын таңдау себептері

**UD English EWT** және **UD English GUM** таңдауы келесі факторларға негізделген:

1. Екі деректер жиынтығы да:

   * **бірыңғай Universal Dependencies схемасын** қолданады;
   * **CoNLL-U** форматында ұсынылған;
   * **морфологиялық белгілерді (FEATS)** қамтиды.

2. Деректер жиынтығының комбинациясы келесілерге мүмкіндік береді:

   * модельді біріктірілген корпуста оқыту (~382k токен);
   * әртүрлі домендерде жалпылау қабілетін тексеру;
   * мәтін жанрының өзгеруіне модельдің тұрақтылығын талдау.

3. Деректер жиынтығы:

   * ашық;
   * қайта жаңғыртылатын;
   * ғылыми жарияланымдарда кеңінен қолданылады.

## 6. Дипломдық жұмысқа арналған тұжырымдама

> *Оқыту корпусы ретінде CoNLL-U форматындағы морфологиялық және POS-таңбалауы бар Universal Dependencies English Web Treebank (EWT) және English GUM деректер жиынтығы таңдалды. Біріктірілген корпус 29 885 сөйлемнен (~489 мың токен) және UPOS|FEATS форматындағы 406 бірегей морфологиялық белгіден тұрады. Екі деректер жиынтығының комбинациясы мәтін жанрлары мен стильдерінің әртүрлілігін қамтамасыз етеді, бұл модельдердің жалпылау қабілетін бағалауға мүмкіндік береді.*
